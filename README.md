A minimal agent running in your terminal.

## Installation

```bash
uv tool install git+https://github.com/kowyo/mini-agent.git@main
mini-agent
```

## Development

```bash
git clone https://github.com/kowyo/mini-agent
cd mini-agent
make prepare
uv run mini-agent
```
